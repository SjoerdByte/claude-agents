# Collaborator Request Code

## How to Find Shopify's Collaborator Request (Access) Code

In Shopify, the collaborator request access code allows you to grant access to your store to other individuals or teams like Anyday. Follow these steps to locate the 4-digit access code:

1. **Access Your Shopify Store Admin:**\
   Log in to your Shopify store admin panel using your credentials.
2. **Navigate to Settings:**\
   Once logged in, navigate to the bottom left corner of the screen and click on "Settings."
3. **Select Users and Permissions:**\
   In the Settings menu, locate and click on "Users and permissions" from the list of options.
4. **Find the Collaborators Section:**\
   Scroll down the page until you reach the section labeled "Collaborators."
5. **Locate the Access Code:**\
   Within the "Collaborators" section, you'll see the 4-digit access code displayed.

   ![](https://files.readme.io/2c023e7-image.png)
6. **Copy the Access Code:**\
   Click on the icon next to the access code to copy it to your clipboard.
7. **Share the Code:**\
   Feel free to either fill out the form you received in your order confirmation with Anyday or simply send us the code, along with your webshop URL, to <onboarding@anyday.io>.

By following these steps, you've successfully located and copied the collaborator request access code in Shopify.
