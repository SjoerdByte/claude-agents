# Integration Overview

Integrating Anyday with your Magento 2 store requires the Quickpay module as a foundation. This overview outlines the essential steps for setting up the Quickpay module, preparing your store for Anyday's split payment solution.

### Key Integration Steps:

1. **Module Installation:** Begin by downloading and installing the Quickpay module for Magento 2.
2. **Configuration in Magento Admin:** Configure the Quickpay module within your Magento 2 admin panel.
3. **Connect Quickpay with Anyday:** Ensure your Quickpay account is set up to facilitate Anyday transactions.
4. **Test and Go Live:** Conduct tests to confirm everything is working correctly before going live with Anyday payments.

***

*If you do not have a Quickpay account, please contact<onboarding@anyday.io> and we will be happy to create a Quickpay account for you at no cost.*
