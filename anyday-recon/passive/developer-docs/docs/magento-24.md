# Setup Guides

Before activating Anyday, the Quickpay module must be installed on your Magento 2 site. Follow these detailed steps to download, install, and configure the module.

### Downloading and Installing the Quickpay Module:

1. **Download the Extension:** Visit the [Magento Github page](https://github.com/Quickpay/magento-v2) to download the Quickpay extension for Magento 2.x.
2. **Install the Extension:** We recommend installing any Magento 2 extension on a staging or local environment first. Follow Magento's official [extension installation guide](https://devdocs.magento.com/extensions/install/) if needed.

### Connecting Quickpay:

1. **Log in to Magento Admin:** Use an administrator account to access your Magento backend.
2. **Configure the Module:** Navigate to **Stores > Configuration > Sales > Payment Methods**. Find Quickpay and click on the Anyday button to activate it.
