# Setup Guides

Activating Anyday on your MCB.Cloud platform is a simple process that involves sending your Anyday API credentials to MCB for setup. Follow these steps to get started:

### Sending API Credentials to MCB:

1. **Locate Your Anyday API Credentials:** You will need your Anyday API Key, Private Key, and PriceWidget Token. If you're unsure where to find these, refer to the [Anyday API Keys documentation](https://developer.anyday.io/docs/anyday-api-keys) for guidance.
2. **Email MCB:** Send an email with your API credentials to <shop@mcb.dk.> Include your Anyday API Key, Private Key, and PriceWidget Token in the message.
3. **MCB Onboarding:** After receiving your credentials, MCB will handle the rest of the integration process, setting up Anyday as a payment option on your MCB.Cloud store.

***

### What to Expect Next:

* **Confirmation from MCB:** You will receive a confirmation once Anyday has been successfully integrated into your MCB.Cloud platform.
* **Test Transactions:** It's recommended to perform test transactions to ensure everything is working as expected.

By entrusting MCB with your Anyday integration, you can focus on your business while they ensure a seamless setup, enabling you to offer flexible payment options to your customers swiftly.
