# Anyday API keys

### How to Find Your Anyday API Keys

Your Anyday API keys are crucial for integrating Anyday's payment solutions with your online store. Follow these steps to locate your API keys:

1. **Access Your Anyday Merchant Dashboard:**
   * Click on [this link](https://my.anyday.io/en/merchant/dashboard/webshop/apikey) to navigate directly to the API keys section of your Anyday Merchant Dashboard. You might be prompted to log in if you are not already.
2. **Log In:**
   * Enter your login credentials to access your Anyday Merchant account. If you do not remember your password, use the 'Forgot your password?' feature to reset it.
3. **Locate API Keys:**

   * Once logged in, you will be taken directly to the "API Key" section under your webshop settings. Here, you will find two critical pieces of information:

     * **API Key:** Used for general API requests.
     * **Private Key:** Used for sensitive operations and should be kept secure.

       <Image align="center" className="border" border={true} src="https://files.readme.io/6bceb04-image.png" />
4. **Copy API Keys:**
   * Copy both the API Key and the Private Key. You will need to enter these keys in the payment module or gateway setup on your e-commerce platform to activate Anyday payment options.
5. **Implement Keys:**
   * Follow the specific instructions for your e-commerce platform or payment gateway to input your Anyday API and Private Keys. This process varies depending on the platform but is typically found within the payment methods or checkout settings.

***

### Important Notes:

Keep your API and Private Keys confidential to protect your account.\
If you encounter any issues accessing your API keys or have questions about the integration process, contact Anyday support for assistance.

By following these steps, you'll have the information needed to integrate Anyday payment solutions into your e-commerce platform, offering flexible payment options to your customers.
