# Anyday payment-processor endpoints extracted from GitHub (q-openapi vector)

## Hosts (confirmed from source code)
https://my.anyday.io           -- Main merchant/customer API host
https://submit.anyday.io       -- KYC/signup form host
https://www.anyday.io          -- Public marketing / signup landing

## Known endpoints (observed in anyday-payments plugins + anyday-io website js)
POST   https://my.anyday.io/api/v1/authentication/login
GET    https://my.anyday.io/api/v1/webshop/mine
POST   https://my.anyday.io/api/v1/orders                       # URL_AUTORIZE (auth required)
POST   https://my.anyday.io/api/v1/orders/{id}/capture
POST   https://my.anyday.io/api/v1/orders/{id}/refund
POST   https://my.anyday.io/api/v1/orders/{id}/cancel
GET    https://my.anyday.io/api/v1/internal/categories
GET    https://my.anyday.io/api/v1/internal/categories/{cat-id} # subCategories exposed
GET    https://my.anyday.io/api/v2/internal/shops                # supports PageSize up to 175, Search, SortBy, CategoryIds[]
GET    https://my.anyday.io/webshopPriceTag/anyday-price-tag-{en|da}-es2015.js  # public widget JS
GET    https://my.anyday.io/price-widget/anyday-price-widget.js                 # public widget JS
GET    https://submit.anyday.io/iziibuy-kyc?pluginid={key}      # KYC flow (per enterprise pluginid)
GET    https://submit.anyday.io/iziibuy-kyc?shopid={shop_id}    # KYC flow (per shopid)

## Query parameters consumed by /api/v*/internal/*
Language, PageSize, display, Featured, SortBy=CreatedDate, Ascending, CategoryIds[], Search, Page, limit
