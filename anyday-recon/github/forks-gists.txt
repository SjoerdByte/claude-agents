- vin-huset  (merchant: Vin-huset; Budolfsen/Vin-huset Shopify theme)
      file: snippets/product-template-default.liquid
      token: 91624fa2e5c0439ba18dd0ced31eacb9
- greenmind.dk (merchant: GreenMind; T-AIMaven/GreenMind Nuxt source)
      file: pages/Product.vue + nuxt.config.ts
      token: loaded from ./ENV as anyDayTagToken (not in repo)

The price-tag-token is a per-merchant widget token used to render the
Anyday installment-estimate component on a merchant's product pages.
It is intended to be public (embedded in client HTML), but the two
leaked plain-text tokens let an attacker enumerate merchant <-> token
mapping and probe any token-scoped endpoints
(my.anyday.io/webshopPriceTag/anyday-price-tag-*.js and whatever
sibling calls that bundle makes).
