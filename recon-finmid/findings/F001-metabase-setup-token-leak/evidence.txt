### Why the token-leak alone is already a confirmed finding

- Metabase deliberately NULLs the setup-token row once the install wizard
  completes; the instance was first created 2022-07-25 (see analytics-uuid
  creation date in the properties body) so the token has been live and
  reachable for approximately 3 years.
- CVE-2023-38646 is the pre-auth RCE in /api/setup/validate that relies on
  exactly this token being still-valid. Metabase's own advisory list the
  setup-token survival as the "defence-in-depth gap" category.
- Only one line of Envoy config today separates this from pre-auth RCE on
  metabase-external.ops.live.finmid.io, which per the leaked site-url is
  on the live ops network.
